# Shared Utilities (`shared/`)

Thư mục này dành cho các hàm tiện ích dùng chung giữa các script học TOEIC trên Study4 trong tương lai, ví dụ:
- Bộ khung UI/CSS thống nhất (`s4-ui`).
- Trích xuất dữ liệu câu hỏi, từ vựng, phiên âm và ví dụ trên trang giải chi tiết.
- Kết nối với **AnkiConnect** (`http://127.0.0.1:8765`) để tạo Flashcard tự động chỉ với 1 click.
